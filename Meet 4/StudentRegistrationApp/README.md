# Meet 4 - Student Registration App

Aplikasi desktop WPF sederhana untuk mencatat registrasi data mahasiswa. Project ini dibuat berdasarkan Hands-On Lab WPF dan memenuhi requirement: jenis control, event button, validasi input, tambah data, hapus data, dan tampilan data.

**Nama:** Leyan Harits R W  
**NRP:** 5025231288

## Fitur

- Input NIM dan nama menggunakan `TextBox`.
- Pilihan program studi menggunakan `ComboBox`.
- Pilihan jenis kelamin menggunakan `RadioButton`.
- Tombol `Simpan`, `Reset`, dan `Hapus Data Terpilih`.
- Data mahasiswa ditampilkan pada `ListBox`.
- Validasi untuk semua field wajib.
- Counter jumlah mahasiswa.
