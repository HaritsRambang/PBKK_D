# Hello World

Aplikasi console sederhana menggunakan C# dan .NET 10. Program ini menampilkan pesan `Hello, World!` pada terminal.

## Persyaratan

- .NET SDK 10.0 atau lebih baru

## Menjalankan aplikasi

Dari folder proyek ini, jalankan:

```bash
dotnet run
```

Output yang diharapkan:

```text
Hello, World!
```

## Build

```bash
dotnet build
```
